# iDrive app interfaces

- Use Speed Limit Romania's native iDrive menu as the model for new display settings. Put the controls on the first page or in directly accessible functional sections.
- Offer left, right, up and down buttons that move by 10 px per press, plus a reset button. Update the display immediately and preserve focus on the last control.
- Use an inline size slider where the UI supports it. Keep HUD and instrument-cluster settings independent.
- Create original icons with transparent borders at 140 × 140 px, with light blue, dark blue and red accents.
